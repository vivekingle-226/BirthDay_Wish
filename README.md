# BirthDay_Wish

# Divya's Birthday Website v2

This is the React website only. No database and no QR generator yet.

## Run it
```bash
npm install
npm run dev
```
Open the localhost URL Vite prints.

## Add Divya's photos
Put 4 images in `public/photos/` and name them exactly:
- `divya-1.jpg`
- `divya-2.jpg`
- `divya-3.jpg`
- `divya-4.jpg`

The gallery has arrow buttons, dot navigation, and touch swipe on phones. If an image is missing, a helpful placeholder appears.

## Add your voice message
Record your own message, export as MP3, and save as `public/voice-message.mp3`.

## Test production build
```bash
npm run build
```
Deploy only after the website looks right on mobile and desktop.
